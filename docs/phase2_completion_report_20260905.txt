2. Data Flow
============
  orchestrator.run()
    → step 2a: assemble_candle_events(events)
    → step 2b: join_ob_features(events)              ← NEW
         → for each symbol:
              → _date_range(min_ms - 300k, max_ms + 60k)  ← extended backward for midnight boundary
              → batch-read parquet files (RECON_DIR / symbol / {date}.parquet)
              → compute_all_features(ob_data)
              → for each event: temporal lookup (snapshot_ms <= event_ms)
                 → quality = "ok" | "gap" | "stale" | "missing"
              → LEFT JOIN back to events DataFrame
    → step 4: data validation (unchanged — OB columns are nullable, pass validation)

3. Semantics — Temporal Invariant
==================================
  CRITICAL: snapshot timestamp <= event T. Never after.

  Quality classification:
    "ok"     — snapshot within 120s of event, no gap detected
    "gap"    — snapshot has gap_detected=True (reconstruction discontinuity)
    "stale"  — snapshot 120-600s old (features populated but stale)
    "missing" — no snapshot within 600s, or no parquet file, or empty parquet

  Date boundary handling: date range extends 5 min backward to catch snapshots
  on the previous calendar day (e.g. event at midnight 09-06, snapshot at 23:59 on 09-05).

  LEFT JOIN semantics: OB columns are nullable. When quality="missing", all OB
  features are NULL. Candle-only pipeline continues to work without modification.

4. Hypothesis Generation
========================
  ob_hypothesis_rules.toml defines 16 whitelist rules for OB features:
    - ob_spread_bps (gt/lt × 2 horizons)
    - ob_imbalance_1,5,10 (gt/lt × 2-3 horizons)
    - ob_top1_share (gt/lt × 2 horizons)
    - ob_depth_change_5_1,10_1 (gt/lt × 2 horizons)
    - ob_spread_change_1 (gt/lt × 2 horizons)

  All rules have max_conditions=2 (compound hypotheses limited).
  hypothesis_generator.all_rules() returns candle rules + OB rules combined.
  Discovery operates across the complete set — no separate OB research engine.
